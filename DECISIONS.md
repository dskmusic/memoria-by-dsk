# Design decisions

| # | Topic | Decision | Why |
|---|-------|----------|-----|
| 1 | Origin | Forked from Genesix by DSK (same GPLv3 codebase, namespace `gx` kept) | Reuse engine, tooling, CI, installer. Genesix itself is never modified. |
| 2 | Plugin codes | Manufacturer `Dskm`, plugin `Mmra`, bundle `com.dskmusic.memoria` | Frozen forever (DAW session compatibility). |
| 3 | Repo visibility | Private until first release; GitHub Actions **disabled at repo level** (workflows are the final public ones) | Private-repo Actions minutes are metered. One API call enables everything on the day it goes public. No public binaries while private (GPLv3: binaries must ship with source). |
| 4 | Commit e-mail | Repo-local GitHub noreply address from the first commit | The history becomes public when the repo is flipped. |
| 5 | Installer | New Inno Setup AppId | Must not upgrade/uninstall Genesix. |
| 6 | Export formats | WAV, FLAC, OGG (JUCE built-in); no MP3 | No extra encoder code/dependency. |
| 7 | Playback | Play/Stop button + follows DAW transport; evolution driven by seed + timeline position | DAW bounces match what was heard. |
| 8 | Determinism | Control decisions on an absolute 32-sample tick grid; random choices from (seed, time-slot) hashes or RNGs reseeded on reset; MIDI events split render chunks | Output is bit-identical for any host block size (tested 512 / 333 / 64). |
| 9 | DAW sync | Engine resets on transport start or position jump; musical time = host position | Bounces and loops reproduce exactly; tails from before the start are dropped by design. |
| 10 | Play state | Runtime flag, not a parameter | A saved project must not start playing on load; the session timer can stop it from the audio thread. |
| 11 | Texture / Shimmer input | Always fed by drone + pad (rendered even when those are muted) | Each layer stays independent: muting the pad doesn't silence the granular cloud. |
| 12 | Idle | After 8 s of silence with nothing playing the engine outputs zeros and skips DSP | Near-zero CPU for stopped instances in big DAW projects. |
| 13 | Factory bank | 5 presets per sub-mood (75), generated by `MemoriaTool factory`, validated + level-matched per mood (-19.5 to -23 dB RMS) | Reproducible; the test suite re-validates a sample on every run. |
| 14 | Removed from Genesix | Arp/gate/seq, SFZ export, FM/wavetable oscillators, mod matrix, 12-slot FX rack, demo-video tool | Not needed for a self-playing ambient instrument; less code to maintain. |
